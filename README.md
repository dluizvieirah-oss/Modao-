# Modão Novo

App de música sertaneja (PWA) que se atualiza sozinho com os lançamentos mais recentes.

## Publicar no GitHub Pages
1. Crie um repositório público e envie todos os arquivos desta pasta para a raiz.
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main` e pasta `/ (root)`.
3. Acesse https://SEU-USUARIO.github.io/NOME-DO-REPO/ e instale pelo menu do navegador.

## Atualizações
Ao alterar o index.html, aumente o número da versão em `CACHE` no sw.js.
